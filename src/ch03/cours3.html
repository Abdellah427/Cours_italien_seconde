Un crochet tourné vers le nombre l’inclut (« fermé »), un crochet tourné vers l’extérieur l’exclut (« ouvert »). Du côté de ∞, le crochet est toujours ouvert : on n’atteint jamais l’infini. Le symbole ∈ se lit « appartient à ».

7.2 Inégalités et opérationsDisuguaglianze e operazioni

Inégalités et addition (p. 94)Disuguaglianze e addizione (p. 94)
  • Ajouter (ou soustraire) un même nombre aux deux membres ne change pas le sens : a < b ⇔ a + c < b + c.
  • On peut ajouter membre à membre deux inégalités de même sens : si a < b et c < d, alors a + c < b + d. Exemple : x > 4 et y > −2 donnent x + y > 2.

Attention, on ne peut pas les soustraire membre à membre : 3 < 5 et 4 < 8, mais 3 − 4 = −1 n’est pas plus petit que 5 − 8 = −3.

  • Aggiungere (o togliere) uno stesso numero ai due membri non cambia il verso: a < b ⇔ a + c < b + c.
  • Si possono sommare membro a membro due disuguaglianze dello stesso verso: se a < b e c < d, allora a + c < b + d. Esempio: x > 4 e y > −2 danno x + y > 2.

Attenzione, non si possono sottrarre membro a membro: 3 < 5 e 4 < 8, ma 3 − 4 = −1 non è minore di 5 − 8 = −3.

Inégalités, produit et quotient (p. 94)Disuguaglianze, prodotto e quoziente (p. 94)
  • Multiplier (ou diviser) les deux membres par un nombre strictement positif ne change pas le sens.
  • Multiplier (ou diviser) les deux membres par un nombre strictement négatif change le sens.

Pour comprendre : 2 < 3, mais −2 > −3. Multiplier par −1 « retourne » la droite graduée, donc l’ordre s’inverse.

  • Moltiplicare (o dividere) i due membri per un numero strettamente positivo non cambia il verso.
  • Moltiplicare (o dividere) i due membri per un numero strettamente negativo cambia il verso.

Per capire: 2 < 3, ma −2 > −3. Moltiplicare per −1 «capovolge» la retta numerica, quindi l’ordine si inverte.

DémonstrationDimostrazione

Si b < c, alors b − c < 0. Si a > 0, a(b − c) est le produit d’un positif par un négatif, donc ab − ac < 0, soit ab < ac. Si a < 0, a(b − c) est le produit de deux négatifs, donc ab − ac > 0, soit ab > ac.

À noter : comparer a et b revient à étudier le signe de a − b.

Se b < c, allora b − c < 0. Se a > 0, a(b − c) è il prodotto di un positivo per un negativo, quindi ab − ac < 0, cioè ab < ac. Se a < 0, a(b − c) è il prodotto di due negativi, quindi ab − ac > 0, cioè ab > ac.

Da notare: confrontare a e b equivale a studiare il segno di a − b.

7.3 Résoudre une inéquationRisolvere una disequazione

Définitions et schéma (p. 94)Definizioni e schema (p. 94)

Résoudre une inéquation, c’est trouver toutes les valeurs de x pour lesquelles l’inégalité est vraie. On donne la réponse sous forme d’intervalle.

Pour ax + b > 0 (a ≠ 0) : ax > −b, puis si a > 0, x > −ba ; si a < 0, x < −ba (le sens change).

Exemple du manuel : −3x + 12 ≤ 0 ⇔ −3x ≤ −12 ⇔ x ≥ −12−3 (on divise par −3, négatif) ⇔ x ≥ 4. Solution : [4 ; +∞[.

Risolvere una disequazione significa trovare tutti i valori di x per cui la disuguaglianza è vera. Si dà la risposta sotto forma di intervallo.

Per ax + b > 0 (a ≠ 0): ax > −b, poi se a > 0, x > −ba; se a < 0, x < −ba (il verso cambia).

Esempio del libro: −3x + 12 ≤ 0 ⇔ −3x ≤ −12 ⇔ x ≥ −12−3 (si divide per −3, negativo) ⇔ x ≥ 4. Soluzione: [4 ; +∞[.

Oublier de retourner le signe quand on divise par un nombre négatif. Astuce : regroupe les x du côté où leur coefficient reste positif (x − 6 > 4x + 3 ⇔ −9 > 3x ⇔ x < −3), il n’y a alors rien à retourner.

8.1 Trois façons de raisonnerTre modi di ragionare

Exemple et contre-exemple (p. 99)Esempio e controesempio (p. 99)
  • Pour montrer qu’une phrase « il existe … » est vraie, un exemple suffit. « Il existe un entier, autre que 1 et 147, qui divise 147 » : 147 = 7 × 21, donc 7 convient.
  • Pour montrer qu’une phrase « pour tout … » est fausse, un contre-exemple suffit. « Pour tout réel x, −x < 0 » est fausse : pour x = −3, −x = 3, qui n’est pas négatif.
  • Mais pour montrer qu’une phrase « pour tout … » est vraie, un exemple ne suffit pas : il faut un calcul valable pour tous les nombres. « Pour tout réel x, x2 + 3x + 2 = (x + 1)(x + 2) » : on développe (x + 1)(x + 2) = x2 + 3x + 2.
  • Per mostrare che una frase «esiste …» è vera basta un esempio. «Esiste un intero, diverso da 1 e 147, che divide 147»: 147 = 7 × 21, quindi 7 va bene.
  • Per mostrare che una frase «per ogni …» è falsa basta un controesempio. «Per ogni numero reale x, −x < 0» è falsa: per x = −3, −x = 3, che non è negativo.
  • Ma per mostrare che una frase «per ogni …» è vera un esempio non basta: serve un calcolo valido per tutti i numeri. «Per ogni x reale, x2 + 3x + 2 = (x + 1)(x + 2)»: si sviluppa (x + 1)(x + 2) = x2 + 3x + 2.
Raisonnement par l’absurde (p. 99)Dimostrazione per assurdo (p. 99)

On suppose le contraire de ce qu’on veut montrer, et on arrive à une contradiction. Exemple : il n’existe pas de triangle ABC avec AB = 5, BC = 3 et AC = 10. Sinon, l’inégalité triangulaire donnerait AC ≤ AB + BC = 8, ce qui contredit AC = 10.

Si suppone il contrario di ciò che si vuole dimostrare e si arriva a una contraddizione. Esempio: non esiste un triangolo ABC con AB = 5, BC = 3 e AC = 10. Altrimenti la disuguaglianza triangolare darebbe AC ≤ AB + BC = 8, in contraddizione con AC = 10.

Disjonction des cas (p. 99)Dimostrazione per casi (p. 99)

On découpe en un nombre fini de cas qui couvrent toutes les possibilités. Exemple : « pour tout entier naturel n, n2 et n ont la même parité ».

  • Si n est pair, n = 2k et n2 = 4k2 = 2(2k2) est pair.
  • Si n est impair, n = 2k + 1 et n2 = 4k2 + 4k + 1 = 2(2k2 + 2k) + 1 est impair.

Dans tous les cas, n2 et n ont la même parité.

Si divide in un numero finito di casi che coprono tutte le possibilità. Esempio: «per ogni numero naturale n, n2 e n hanno la stessa parità».

  • Se n è pari, n = 2k e n2 = 4k2 = 2(2k2) è pari.
  • Se n è dispari, n = 2k + 1 e n2 = 4k2 + 4k + 1 = 2(2k2 + 2k) + 1 è dispari.

In tutti i casi n2 e n hanno la stessa parità.

8.2 Démontrer que deux expressions sont égalesDimostrare che due espressioni sono uguali

Règle d’orRegola d’oro

On ne part jamais de l’égalité à démontrer : elle n’est pas encore connue. On calcule chaque côté séparément, ou on part d’un côté pour arriver à l’autre.

Non si parte mai dall’uguaglianza da dimostrare: non è ancora nota. Si calcola ogni lato separatamente, oppure si parte da un lato per arrivare all’altro.

8.4 Algorithme : la première puissance qui dépasseAlgoritmo: la prima potenza che supera

Méthode résolue · Algorithme 13 (p. 97)Metodo svolto · Algoritmo 13 (p. 97)

On cherche le plus petit entier k tel que 3k > N. On part de k = 0 et on ajoute 1 tant que 3k ≤ N ; la boucle s’arrête dès que 3k dépasse N.

Si cerca il più piccolo intero k tale che 3k > N. Si parte da k = 0 e si aggiunge 1 finché 3k ≤ N; il ciclo si ferma appena 3k supera N.

def depasse_puis3(N):
    k = 0
    while 3**k <= N:
        k = k + 1
    return k

>>> depasse_puis3(500000)
12
